# Invitación de boda Ale & Leo - POO

Proyecto desarrollado con:

- HTML5
- CSS3
- JavaScript
- Programación Orientada a Objetos (POO)

## Clases utilizadas

### WeddingConfig
Centraliza todos los datos de la boda.

### Countdown
Controla la cuenta regresiva.

### ScrollAnimations
Maneja las animaciones al hacer scroll usando IntersectionObserver.

### ColorPalette
Genera dinámicamente la paleta de colores.

### WeddingInvitation
Es la clase principal que conecta todas las demás clases y pinta la información en la interfaz.

## Imágenes

Coloca tus fotografías en la carpeta `imagenes` con estos nombres:

- portada.jpg
- dress-mujer.jpg
- dress-hombre.jpg
- foto-final.jpg

## Datos principales

Para modificar la boda abre:

`script.js`

y cambia los datos dentro de:

`class WeddingConfig`
